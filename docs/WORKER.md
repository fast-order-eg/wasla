# وكيل التشغيل المحلي

الوكيل الحالي مستقل عن الردود السحابية، ووظيفته تسجيل نبضة اتصال وفحص منفذ بروكسي الموبايل. حالته تظهر في لوحة التحكم. لا ينشر، لا يفتح حسابات، لا يرسل رسائل، ولا يغيّر IP أو وضع الطيران. لا يشغّل AdsPower أو ADB.

## تشغيل محلي

1. شغّل السيرفر حسب README واضبط `WORKER_API_KEY` فيه على قيمة سرية عشوائية لا تقل عن 32 حرفًا.
2. انسخ `worker/.env.worker.example` إلى `worker/.env` وضع نفس المفتاح. الملف محلي وسري، ولا تضع المفتاح في عنوان URL أو سطر الأوامر.
3. طابق `CLOUD_BASE_URL` مع عنوان ومنفذ السيرفر الفعلي. العنوان الافتراضي في المثال `http://127.0.0.1:3080`.
4. لو البروكسي غير جاهز، اترك `MOBILE_PROXY_URL` فارغًا. النبضة ستصل بحالة `degraded` وفحص `not_configured`؛ هذا لا يعني فشل اتصال السيرفر.
5. من جذر المشروع على Node.js 22، نفّذ:

```powershell
npm run worker -- --once
```

للتشغيل المستمر استخدم `npm run worker`. ويمكن تشغيله مباشرة بالأمر `node --env-file=worker/.env worker/index.mjs --once`. للإيقاف استخدم Ctrl+C. التشغيل يدوي في هذه النسخة؛ لم تتم إضافة خدمة Windows أو مهمة بدء تشغيل.

## معنى نتيجة الفحص

`online` هنا يعني أن نبضة السيرفر نجحت ومنفذ البروكسي قبل اتصال TCP فقط. **لا يثبت الفحص** أن البروكسي يعمل ببروتوكول SOCKS/HTTP الصحيح، أو أن كلمة مروره صحيحة، أو أن الإنترنت خارج من الشريحة، أو أن أي حساب معزول. لا نفحص عنوان IP العام ولا نتصل بخدمة خارجية لفحصه.

الوكيل نفسه يتصل بالسيرفر مباشرة باستخدام اتصال الجهاز؛ متغير البروكسي لا يغير إعدادات الشبكة ولا يوجه اتصالات Node عبر الموبايل. توجيه المتصفحات إلى بروكسي الموبايل يحتاج إعدادًا منفصلًا واختبارًا فعليًا قبل اعتباره جاهزًا.

## اتصال الإنتاج

استخدم عنوان `https://` للسيرفر، وأزل سماح HTTP المحلي. HTTP يُسمح به فقط إلى `localhost` أو `127.0.0.1` أو `::1` ومع `ALLOW_LOCALHOST_HTTP=true`. لا يقبل الوكيل بيانات دخول داخل URL، ولا يعيد توجيه طلب يحمل مفتاح API إلى عنوان آخر.

مهلة طلب السيرفر الافتراضية 10 ثوانٍ، ومهلة فحص البروكسي 3 ثوانٍ. عند تعذر الوصول للسيرفر، يعيد المحاولة بانتظار متزايد محدود ثم يتوقف بعد خمس محاولات فاشلة متتالية. خطأ المصادقة أو سياسة غير مدعومة يوقفه فورًا للمراجعة. انخفاض حالة البروكسي وحده لا يوقف النبضات، لكي تظل المشكلة ظاهرة في اللوحة.

السجلات تعرض أكواد أخطاء ثابتة ولا تطبع المفتاح أو عنوان البروكسي أو نصوص استجابة السيرفر. عند توقف الوكيل، ينبغي اعتبار نبضته قديمة في اللوحة؛ لا يمكنه إرسال تنبيه سحابي أثناء انقطاع اتصال السيرفر نفسه.

## الاختبارات

```powershell
node --test tests/worker.test.js
```

تتحقق الاختبارات من إعدادات الشبكة، رفض عناوين HTTP غير المسموح بها، مهلة الطلب، عدم تسريب الأخطاء، حد المحاولات، رفض سياسة دوران العناوين، وفحص TCP محلي حقيقي. لا تتصل بفيسبوك أو AdsPower أو أي حساب خارجي.
