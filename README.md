# وصلة — إدارة البيع والمحادثات

نسخة محلية قابلة للتجربة لإدارة المنتجات، الرسائل المسجّلة، مسودات الردود، الأوردرات والمخزون وتجهيز النشر. **ليست نظام نشر أو إرسال تلقائي جاهزًا على حسابات فيسبوك الشخصية.**

## افتحها الآن

يتطلب Node.js 22.13 أو أحدث. من مجلد المشروع:

```powershell
npm.cmd install
npm.cmd start
```

افتح http://127.0.0.1:3080 — كلمة مرور التجربة `demo-only`.

الوضع الافتراضي محلي فقط. البيانات تتحفظ في `data/commerce.sqlite`، وتظل موجودة بعد إعادة التشغيل. يوجد منتج ومحادثة مثال فقط، بدون مبيعات مزيفة. لا توجد اتصالات AI خارجية أو إرسال لعملاء في وضع التجربة.

## تجربة مسار كامل

1. افتح المحادثة التجريبية، واختار «اقترح رد». الناتج مسودة، لم يتم إرسالها.
2. سجّل بيانات عميل **تجريبية**، بما فيها اللون والمقاس المطلوبان للمنتج المثال.
3. أنشئ أوردر وحدد الكمية وتكلفة الشحن المعروفة. السعر من المنتج، وليس من الذكاء الاصطناعي.
4. افتح الأوردر؛ سجّل تأكيد العميل الصريح. عندها فقط يُحجز المخزون، بعد إعادة التحقق من السعر والتوفر.
5. تابع التجهيز والشحن والتسليم. إلغاء الطلب المؤكد يرجع المخزون مرة واحدة.
6. «مرتجع» يعني أنك استلمت القطع وفحصتها وأصبحت صالحة للإرجاع للمخزون؛ لا تستخدمها لمجرد طلب إرجاع أو مرتجع تالف.
7. جهّز منشورًا من المنتج، وانسخ محتواه. تسجيل «منشور» في اللوحة توثيق يدوي، وليس إرسالًا إلى فيسبوك.

## ما تم تنفيذه

- لوحة عربية RTL مناسبة للشاشات الصغيرة، تسجيل دخول، نظرة عامة، منتجات، محادثات، طلبات، تجهيز نشر، وقنوات ومراقبة تشغيل.
- API مع التحقق من البيانات، أسعار بالقروش الصحيحة، منع تكرار الطلب المفتوح، حجز مخزون ذري، سجل حالات، ومنع التكرار عند إعادة الإشعارات.
- حفظ محلي SQLite؛ محوّل MySQL للإعداد على السيرفر. **MySQL لم يُختبر على خادم فعلي بعد.**
- مساعد محلي بالقواعد، ومحوّل اختياري لـGemini API عندما تختار موديلًا مدعومًا وتوفر المفتاح. جميع النتائج مسودات تحتاج مراجعة.
- استقبال Messenger عبر Webhook موقّع، حفظ الإشعار قبل الرد على Meta، طابور معالجة دائم، إعادة محاولة محدودة، وحجب بيانات الإشعارات من سجل التشغيل.
- وكيل محلي اختياري لفحص منفذ البروكسي وإرسال نبضات اتصال. لا يغيّر الشبكة أو الـIP أو يفتح حسابات.
- اختبارات فعلية لدورة الأوردر والتزامن والتأكيد المكرر والتدخل البشري والمصادقة والإشعارات والوكيل.

## حدود النسخة الحالية

- **لا إرسال خارجي ولا نشر تلقائي**، حتى مع إعداد Webhook. المتاح استقبال ومسودات ونسخ وتسجيل يدوي.
- الحسابات الشخصية وMarketplace غير مربوطة بصندوق رسائل موحّد؛ الإدخال اليدوي ليس مزامنة.
- مخزون إجمالي للمنتج؛ قائمة الألوان والمقاسات للتوثيق فقط، وليست مخزون SKU مستقلًا.
- الشحن يُدخل يدويًا حسب السعر المتفق عليه؛ جداول تسعير الشحن والربط بشركة شحن ضمن المهام التالية.
- مدير واحد، جلسات بالذاكرة تنتهي عند إعادة تشغيل السيرفر. لا أدوار فريق متعددة أو استرجاع كلمة مرور في هذه النسخة.
- التخزين `app_records` يحتوي سجلات JSON بمعاملات وقفل تطبيق؛ العلاقات تُراجع في التطبيق. ليس مخطط SQL مطبعًا مناسبًا لتوسع كبير. يجب تطبيعه واختبار تحميل قبل التوسع.
- التاريخ والوقت في الواجهة حسب متصفح المستخدم، والسجلات مخزنة UTC.
- لا ادعاء بحماية من الحظر، ولا اعتماد على تدوير IP أو تغيير صور لتجاوز اكتشاف التكرار.

